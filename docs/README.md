## Documentation rules
1. **Code and docs change in the same PR.** A PR that changes behaviour without updating docs is incomplete.
2. **Every `src/` module has a doc** in `docs/modules/<module>.md` (from the template),
   and every source file starts with a header comment: purpose, key exports, related doc.
3. **HLD** changes when components, data stores, integrations or flows change.
4. **ADR** for every decision affecting architecture, dependencies, data model, security or integrations.
5. **LLD** is generated by `npm run docs` (runs in the pre-commit hook). Never edit it by hand.
